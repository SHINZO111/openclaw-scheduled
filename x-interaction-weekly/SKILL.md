## Step 3: 返信候補の生成

確認できた返信・メンションについて、返信候補文を生成する。

**返信ポリシー**:
- AI技術に関する質問 → 丁寧に回答（専門性アピール）
- 「参考になりました」系 → 感謝＋次回投稿予告
- 批判的なコメント → 事実ベースで穏やかに返答
- スパム・荒らし → 無視（返信しない）

返信候補を `interaction-log.md` に追記:
```
### 返信候補 YYYY-WXX
| 対象ツイート要約 | 推奨返信文 | 優先度 |
|--------------|--------|-------|
| [要約] | [返信文（140字以内）] | 高/中/低 |
```

**注意**: 実際の返信はSHINZOが確認・送信する。自動送信はしない。

## Step 4: フォロワー傾向分析

新規フォロワーのプロフィール傾向から:
- どの職種・興味層が増えているか
- どのコンテンツが新規フォロワーを呼んでいるか

を分析し、x-performance-log.md の今週セクションに追記:
```
#### フォロワー傾向（YYYY-WXX）
- 増加傾向: [職種/興味]
- きっかけトピック: [推定]
```

## Step 5: エンゲージメント強化提案

確認したインタラクションから、エンゲージメントを高める投稿改善を提案:

- 「AIエージェント投稿への返信が多い → 毎週1本AIエージェント深掘り投稿を追加」
- 「質問形式の投稿に返信が集中 → 全トピックに問いかけ文を加える」

提案を `interaction-log.md` の「改善提案」セクションに記録。

# stop-slop X投稿品質チェック

投稿前に以下のチェックを実行し、1つでも該当すれば修正してから投稿すること。

## 禁止フレーズチェック

以下を含んでいたら**必ず削除・書き換え**:

**【喉清めオープナー】** → 削除して直接本題に入る
- 「ここで重要なのは」「実は」「本当のところ」「正直なところ」「問題は〜」
- いわゆるthroat-clearing。この手の前置きは全てカット。

**【強調のクセ】** → 削除（意味がない）
- 「これが全てだ」「間違いなく」「言わせてくれ」「考えてみてほしい」

**【副詞】** → 全削除
- 「実は」「本当に」「まさに」「単に」「実際に」「非常に」「確かに」「深く」「まさしく」「興味深いことに」
- -ly系副詞も全て削除（really, literally, actually, simply 等）

**【曖昧な一般論】** → 具体的に言い換え
- 「理由は構造的だ」「影響は大きい」「本質的な問題だ」「意味するところは深い」
- 代わりに「具体的に何が」を書く

**【メタコメント】** → 削除
- 「ヒント」「ネタバレ」「この記事の残りでは説明する」「見ていこう」

**【ビジネスジャーゴン】** → 平易な表現に
- ナビゲート/アンパック/ゲームチェンジャー/ランドスケープ/ディープダイブ 等

## 構造チェック

**【二者対比】** → Yを直接述べる
- 「XではなくY」「問題はXではない。Yだ」「重要なのはXじゃない。Yだ」
- 否定で始めてから肯定に転じる構造は全部カット。Yだけ言え。

**【否定リスト】** → 削除
- 「Xじゃない。Yじゃない。Zだ。」のような否定の積み上げは削除。Zを直接言え。

**【劇的フラグメント】** → 削除
- 「○○。それだけだ。」「これが△だ。」のような1語区切りは削除。完全文で書け。

**【修辞的設問】** → 削除
- 「もし〜だとしたら？」「つまりどういうことか？」「考えてみよう」
- 読者に問いかけるフリしてるだけ。断定しろ。

**【無生物主語】**
- 「決定が生まれる」「文化が変わる」「データが教えている」
- 実際にやった人間を主語にしろ。人間が見えない文章はAI確定。

**【三人称ナレーター視点】**
- 「誰もこれを設計しなかった」「人々は〜しがちだ」
- 「あなたは〜」で読み手をその場に置け。

**【受動態】** → 能動態に
- 「〜された」「〜されている」→ 誰がやったかを主語に置く。

## リズム・文体チェック

- 3連続で同じ長さの文がある？ → 1つ崩せ
- パラグラフの終わりが全部強調ワンライナー？ → バラせ
- 「問題は」「重要なのは」が2回以上出てる？ → 削除
- 全文同じ長さの短文→改行の繰り返し？ → 長短混ぜろ
- 「衝撃」「革命」「パラダイムシフト」が入ってる？ → 削除
- emダッシュ（—）を使ってる？ → 削除

## 簡潔化

- 言い換え可能な箇所は全て短く
- 「〜することによって」→「〜で」
- 「〜というわけではないが、〜する必要がある」→「〜が必要」
- 修飾節を省いても意味が通じるなら削除

## 最終スコアリング

各次元 1-10:

| 次元 | 質問 |
|------|------|
| 直接性 | 主張しているか、それとも前置きしているか？ |
| リズム | 変化があるか、単調か？ |
| 信頼 | 読者の知性を尊重しているか？ |
| 自然さ | 人間が書いたように聞こえるか？ |
| 密度 | 削れる箇所はないか？ |

合計35/50未満 → 修正してから投稿。
